# 赞助商广告牌

广告现在从 Cloudflare `/api/sponsors` 读取，`config.json` 是此前的空白占位配置，已不再控制上架。请在现有 `/admin` 的「赞助申请」中管理合作与档期。

- 三页循环，每页约 8 秒，页面之间横向滑动。打开合作介绍时暂停自动翻页，可手动切页或暂停。
- 每页分别保留核心、硬件、社区三个位置；空位显示招募中。
- 核心：第 1 页 ¥100/月、¥1000/年；第 2 页 ¥80/月、¥800/年；第 3 页 ¥50/月、¥500/年。价格以服务端返回与申请快照为准。
- 硬件按项目合作，社区按活动、展位和 swag 合作，均需提交关联事项及资源说明。
- 点击「申请合作 / 查看进度」提交 Logo、官网、联系方式和期望档期。Logo 客户端转换为白底 JPEG，服务端再次校验并去除元数据。
- 联系方式、资源详情和回执不进入公开广告接口。申请记录凭当前浏览器保存的随机回执查询。
- 审核通过 + 人工确认收款或资源 + 当前时间在档期内，才会公开广告和 Logo。到期、暂停、未通过均不公开。
- 每个类别的同一轮播页不能安排重叠档期，由数据库触发器保证。月／年按北京时间自然月／年计算，月末取目标月最后一天；活动结束日期包含当天。
- 广告接口每 30 秒刷新，已知到期时间在画面更新时检查；减少动态效果设置下不自动翻页，仍可手动切页。
- 微信支付尚未接入。当前没有下单、扣款、自动续费、自动退款或支付回调接口；由管理员人工核实后确认合作。申请本身不锁定档期。

后端迁移及校验位于 `services/community-wall/migrations/0002_sponsors.sql` 和 `src/sponsors.js`。接口沿用共创墙的私有 R2、D1、审核密钥与精确来源白名单。
