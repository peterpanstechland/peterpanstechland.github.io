# 工位搭子 · 视觉与交互规范

网页与实体屏共享安静、轻巧、略带幽默的视觉语言。实体屏的布局与功能见 [Indicator 界面](../indicator-ui.md) 和 [养成规则](../indicator-garden.md)。

## 1. 一眼认出的产品气质

**安静的工业物件，里面住了一个有梗的小生命。** 外层用克制的排版、清晰结构和精确数据；内层用叶片、眼睛、短句和一次小庆祝制造亲近感。高级感来自节奏和细节，而不是大量玻璃卡、霓虹线、旋转模型同时出现。

当前网页采用 Minecraft 启发的方块风格：Creeper 头花盆、草方块底座、像素粒子、直角边框与合成台式按钮。纸白和浅绿留出阅读空间，深绿负责文字与边界；像素感来自轮廓、纹理和交互，不牺牲中文可读性。实体屏保留现有像素精灵和八套原生主题。

HONOR Robot Phone 与 Seeed Studio 的名称在首屏露出。产品照片保留原貌，旁边写具体型号、项目用途及官方链接，统一整理在 [硬件图鉴](hardware-catalog.md)。网页 3D 花盆是交互预览，产品实图用于认板，两者的说明分别保留。

## 2. 设计 token

| 用途 | 建议值 | 使用规则 |
| --- | --- | --- |
| 主背景 `ink` | `#233B28` | 正文、按钮边框与深色收尾区 |
| 次背景 `ink-soft` | `#345C32` | 主按钮与合成台选中态 |
| 纸白 `paper` | `#F3F1DF` | 长文背景、主文字、实物说明卡 |
| 正文 `text` | `#233B28` | 纸白背景上的正文 |
| 次级文字 `muted` | `#53634F` | 纸白背景；深色背景改用 `#B8C2B6` |
| 主强调 `lime` | `#B6E568` | 选中态、关键步骤、少量花叶高光 |
| 泥土 `dirt` | `#87603D` | 草方块侧面与少量空间点缀；不单独承担错误语义 |
| 点缀 `lilac` | `#C9BAEC` | 性格、短句和游戏奖励，不能替代状态语义 |
| 信息 `sky` | `#A8D9E6` | 查询、数据路径、链接强调 |
| 待确认 `amber` | `#F4CA73` | 旧数据、进行中、需要人确认 |
| 故障 `coral` | `#F09882` | 异常信息，搭配文字和图标，不只变红 |
| 圆角 | 网页 0 px | 直角控件与方块面板；实体屏沿用原生主题 |
| 间距 | 4 / 8 / 12 / 16 / 24 / 32 / 48 / 72 / 96 px | 标题离自己正文更近，离上一区块更远 |

文字与重要控件上线前逐项量测对比度：正文至少 4.5:1，大字和必要非文字边界至少 3:1。酸橙色按钮优先配 `ink` 深字，不直接用纸白字。图表和状态必须有文字、纹理或形状的第二编码。

建议字体栈：正文 `"Noto Sans SC", "PingFang SC", "Microsoft YaHei", sans-serif`，英文标题可用系统无衬线，技术标识使用系统等宽。优先打包已授权字体，并提供系统字体回退。网页正文建议 16–18 px、行高 1.65–1.8、每行约 30–40 个汉字；移动端避免三列文字卡。

屏幕继续用现有原生 16/24/32/48/64 px 位图字库。新增中文短句需要重生成字库并跑覆盖检查；不直接把网页字体配置复制给 MCU。

## 3. 信息架构与页面节奏

### 项目主页

1. **首屏：认领方块搭子。** Creeper 头花盆、简短主张、可旋转角色与互动按钮。直接显示 HONOR / Seeed 硬件来源，提供教程入口。
2. **硬件装备。** 三张官方产品图展示 Robot Phone、XIAO ESP32-S3 Plus、Indicator D1，点击可到产品页或对应教程。
3. **接线合成台。** 切换板卡和外设，探索接口或练习接线，依次核对电源、信号与验证方法。
4. **日常与心情。** 三个工位场景和四种主动选择的状态，让角色替你说一句。
5. **自己接一台。** 从现有 XIAO 套件、自带硬件、YOYO Skill 三条路径进入教程，随后查看功能进度。
6. **旧存档与收尾。** 早期奶油色一体机模型放在折叠区，用户点击后才加载模型，主线继续围绕现在的方块花盆。

移动端将产品卡排成单列，保留图片和官方链接。主要按钮有像素立体边缘、按下位移和键盘焦点圈，不弹出购买或关注层。

### 长教程页

每篇开头说明用途和所需器材。正文采用一步一图、一段可复制命令、一条预期结果、一条失败分支。针脚图同时写板侧名称、GPIO 与供电等级；颜色只能辅助，不能靠红线黑线猜电源。每张截图标版本与日期，账号、密码、token 遮盖；遮盖后检查缩略图也看不到。

### 480×480 实体屏

当前五页为植物精灵、今日状态、信息、照片、番茄钟。后续视觉变化仍应保留这条用户心智：**养成在首页，设备在状态页**。新增界面用词时同步更新字库和渲染测试。

候选控件尺寸为至少 44×44 逻辑 px，关键停止控件更大；在实际电容屏上测误触与拇指可达性。页面切换与滑动离开确认页不提交动作。状态文字不能被粒子遮住，长设备名不能挤掉断线提示。

## 4. 双层交互：情绪轻，动作重

**轻交互层**包括浏览、换主题、选择主动氛围、本地小游戏、网页示意。这一层可以俏皮、可撤回、有短动画。

**设备层**包括读取、真实浇水、开灯、停止、打印。这一层用明确动词、目标、参数、时间和结果。不把“给它一点爱”当成开泵按钮，也不让点赞、摇手机、NFC 触碰自动构成硬件授权。

真实动作确认文案示例：

> 给真实花盆浇水？
>
> 设备：RoboPlanter-XXXX　时长：1 秒
>
> 这是一次水泵动作；尚未标定流量，不显示毫升。
>
> **确认浇水 1 秒**　取消

确认后锁住重复提交入口，保留停止；先显示“设备已受理，等待结果”，收到完成才显示“本次任务已完成”。不把 `completed` 扩写成“已浇足”“植物恢复健康”；打印完成只可解释为串口发送完成，除非有相应设备反馈。

## 5. 所有状态都要有设计

| 状态 | 主文字 | 可用操作 | 禁止的视觉暗示 |
| --- | --- | --- | --- |
| 未配置 | “尚未绑定花盆” | 看接入教程、填写已支持配置 | 在线绿点、实时数字 |
| 查询中 | “正在读取设备” | 取消/离开，不触发动作 | 无限转圈却没有错误出口 |
| 新鲜有效 | “刚刚读取 · 土壤相对湿度 48%” | 查看来源与标定；按能力操作 | 把相对指数写成土壤含水率 |
| 未标定 | “已有原始值，尚未标定” | 查看校准教程 | 给原始 ADC 加百分号 |
| 数据过期 | “这是旧读数 · 12 秒前” | 重新查询、查看连接 | 继续用绿色健康结论 |
| 功能未启用 | “水泵未启用” | 查看接入条件 | 灰按钮无解释、假装执行 |
| 受理中 | “设备已受理，等待结果” | 查同一 ID、停止 | 提前喷出成功粒子 |
| 任务完成 | “本次软件任务完成” | 查记录、结合现场确认 | 无流量计却显示已浇 30 ml |
| 被拒绝 | “没有执行：设备忙碌” | 解释原因、待空闲后由用户新建意图 | 默默排队或自动重试 |
| 结果未知 | “结果未确认，请核对现场” | 查原 ID、停止 | 换 ID 再来一次、“失败所以没浇” |
| 重启后查无记录 | “当前设备无此记录，不能判断此前结果” | 现场检查 | 把空记录当作安全重试许可 |
| 游戏保存失败 | “成长暂未保存” | 保留游玩、重试持久化 | 显示已云同步 |

“刚刚读取”示例只在真实时间戳与有效性满足时出现。网页演示状态顶端始终有“演示状态，可切换”；不做与真实设备面板无法区分的假遥测。

## 6. 动效预算与视觉惊喜

### 第一层：所有设备都能看懂

首屏先显示静态产品图和正文，脚本、3D 或纹理失败不影响教程、状态解释和导航。文字与交互由 HTML 承担，Canvas 不能成为唯一内容。键盘有焦点圈；按钮可用 Enter/Space；图有替代说明；视频有字幕与逐字稿。系统减少动态、页面后台或手动静音模式时停止非必要动画。

### 第二层：网页粒子与 shader

设计一个“呼吸叶场”：鼠标或触点经过时，少量叶形粒子偏转再回到原位；滚动到架构页，粒子聚成一条请求路径。每段动效只讲一个意思：意图聚合、请求送达、等待结果、收到回包。等待期间是缓慢脉冲，未知时路径停在断点；成功粒子只在**明确的演示完成事件**或经接入验证的真实完成事件后发出。

当前展示页采用本地托管的 Three.js 0.180.0、程序化方块角色和 150 个方形点精灵；DPR 上限 1.75，渲染上限约 30 fps。WebGL 不可用时显示静态角色，弱动效偏好下停止角色运动与粒子；页面隐藏时暂停渲染。完整的请求路径动画仍是未来设计。性能测试需记录机型、浏览器和网络条件。

### 第三层：子弹时间与高斯泼溅

**已实现**的是程序化 3D 方块花盆、粒子定格后视角环绕、四种心情文案、3:4 海报和横版封面导出。这里没有使用训练或重建的 3D Gaussian Splatting；粒子使用方形裁切 shader 绘制。

展示页“旧存档”折叠区另有 **Tripo v3.1 一体机静态外观模型**，内嵌手机仓、屏幕、小票和绿植共用一个造型。模型为约 45 MB 的带贴图 GLB，页面先展示轻量预览图，用户点击后才下载；可旋转、重置和主动开启转台，也可返回图片卸载三维视窗。模型用于外观预览，工程结构另行设计。模型视窗采用隔离的本地 Three.js 0.170.0，与角色演示分别运行；隐藏页面或滚出对应视口时暂停渲染。

实物扫描与高斯重建尚未加入。

### 性能验收目标

- 无 WebGL、加载失败、JavaScript 关闭时，产品简介与接入教程仍可读。
- 在记录了型号、浏览器、网络与构建号的至少一台中档 Android 手机上验证；不只测开发机。
- 首屏关键内容出现目标 ≤2.5 秒、交互响应目标 ≤200 ms、展示动效目标稳定 ≥30 fps；测量时记录设备与网络条件。
- 隐藏标签页停止渲染，关闭动态后 GPU 活动明显下降；连续查看 10 分钟观察温升和电量趋势，记录温升与电量变化。
- 主下载尽量控制在可测量范围内；3D/扫描资源分包按需加载。检查 gzip/brotli 后的实际下载大小。

## 7. 组件与素材清单

### WS2813 环境灯：已有模式与后续联动

软件已提供 `solid`（常亮）、`breath`（呼吸）、`chase`（流动）、`rainbow`（彩虹）四种模式，默认关闭，原有灯光开关命令保持兼容；亮度与灯珠数量由构建配置决定。接入新灯带时检查颜色、亮度和时序。 网页的“关 / 柔绿 / 呼吸 / 流动 / 彩虹”是独立概念预览，不是实物回显。

| 已有软件模式 | 设计意图 | 当前表现与待验收点 |
| --- | --- | --- |
| 常亮 `solid` | 稳定的桌面氛围 | 固定绿色；实测反光与可接受亮度 |
| 呼吸 `breath` | 安静地存在 | 软件按 4 秒周期平滑明暗变化；确认实际灯带无刺眼跳变 |
| 流动 `chase` | 轻量的方向感 | 沿灯珠移动；仅一颗灯珠时退化为呼吸，实际视觉取决于数量与排布 |
| 彩虹 `rainbow` | 用户主动选择的小庆祝 | 软件按 12 秒颜色周期渐变；确认实际颜色、供电与观感 |

专注柔光、完成短庆祝、断线低刺激提示是**后续事件联动设计**，当前没有 YOYO 语义、本地番茄钟或植物健康判断与灯效的自动绑定。未来若增加完成反馈，只在取得明确事件后短暂呈现并返回原模式；连接异常仍以文字解释，不把颜色当作唯一判断。

每种模式都需提供关闭方式，记住用户亮度偏好，并在工位环境检查反光、夜间刺眼和拍摄频闪。故障、停泵与动作结果仍由文字和设备回包表达。WS2812 在本项目中用于桌面环境光。

界面可复用状态卡、动作确认、结果列表、步骤说明和角色旁白等内容模块。

拍摄素材至少包括：桌面全景、屏幕近景、XIAO 与接口、干湿标定过程、独立供电与驱动、一次连续的动作闭环、一次断线后的界面。人物只拍获准的人；原始素材另存，不提交含账号与凭证的屏幕录像。

导出首屏横图、3:4 封面、9:16 视频、1:1 头像时保留同一角色比例与颜色。网页提供的“给模拟搭子浇水”“换心情”“子弹时间”和“导出 3:4 海报”必须在操作附近标记模拟身份；导出海报也保留“网页交互角色 / 原型项目”，避免脱离页面后被误认成实物产品照。像素角色使用整数倍缩放和最近邻采样，保持边缘清晰。

## 8. 可访问性与适配

检查移动端单手操作、200%缩放、键盘焦点、减少动态、弱网和离线状态。图片提供替代说明，视频提供字幕；错误信息给出可执行的恢复方法。
