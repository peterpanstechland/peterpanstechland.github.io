# RoboPlanter 工位搭子

> 你先下班，我负责发芽。

RoboPlanter 把真实绿植、像素植物和 YOYO 对话放在同一张工位上。你可以查看盆栽状态，在屏幕上照顾小精灵，开始一段专注，或用一句话与它交流。

它从一盆工位绿植开始，也为自带传感器、控制板和外设的开发者提供接入方式。

## Creeper 头里，住一盆绿

当前花盆使用 Creeper 头造型，网页也采用方块场景和像素交互。方方正正的外壳负责好认，真实植物负责慢慢生长。

硬件来自 **HONOR 与 Seeed Studio**：Robot Phone 上的 YOYO 负责对话，XIAO ESP32-S3 Plus 与 Robot Board 负责外设，SenseCAP Indicator D1 负责桌面显示。[产品实图与官方链接](hardware-catalog.md) 列出了具体型号和各自用途。

## 让照料轻一点

工位上已经有很多需要处理的事。照顾一盆植物，应该是一次轻松的停顿：看一眼读数，观察有没有新叶，记下一次浇水，然后继续手头的工作。

屏幕里的植物精灵提供轻量互动，真实植物按照自己的季节生长。专注奖励可以改变精灵的表情和游戏进度；植物的生长阶段则来自实际观察。两种记录的关系见 [植物生长与陪伴养成](plant-companion.md)。

## 一张工位上的四个角色

- **YOYO**：自然语言入口，通过 Skill 解释状态、处理明确的设备请求。
- **XIAO**：设备控制器，提供 BLE 和 HTTP 接口，负责采样、动作时限和结果查询。
- **SenseCAP Indicator**：本地屏幕与触摸终端，提供植物养成、状态显示、照片、主题和番茄钟。
- **项目网页**：介绍产品、展示 Creeper 头花盆的方块交互场景，并提供互动预览和接入教程。

Indicator 经 Wi-Fi/HTTP 与 XIAO 通信，手机经 BLE 连接 XIAO。具体连接方式见 [硬件入门](hardware-quickstart.md) 和 [YOYO Skill 教程](honor-platform.md)。

## 日常使用

到工位时，先看一眼植物和屏幕。状态页显示已接入传感器的数据；未校准的土壤探头显示原始 ADC，校准后再使用相对湿度。

想专注一会儿，可以在 Indicator 上启动主控共享的番茄钟；YOYO语音控制已实现、手机端仍待验收。想换换心情，可以切主题，照顾屏幕里的精灵，或者选择灯带模式。虚拟照料只影响游戏，不启动真实水泵。

下班后可以关闭设备。屏幕游戏暂停，真实植物继续生长；下一次观察时，再记录新叶、花蕾或果实的变化。

## 产品设计

### 状态清楚，互动轻巧

读数、时间和设备结果优先显示，表情负责陪伴。缺少数据时显示等待或离线，不用拟人台词代替测量。

### 照料由你决定

真实动作使用明确的设备名、参数和操作按钮。查询状态、点击游戏或碰触NFC不会自动浇水。明确的打卡/会议/休息等表达可在自动打印开启时生成日签，支持关闭且有冷却；详见[场景交互](yoyo-companion.md)。

### 离开也没有负担

角色不靠催打卡、内疚提醒或连续签到制造压力。一句短话、一次眨眼和一个可随时结束的小互动就足够。

### 硬件可以逐步接入

先接一个传感器，再加入灯带、打印机等外设。设备型号、协议和驱动由适配层管理，接入新板卡时可以复用上层能力描述。

## 一点光，一点性格

灯带提供常亮、呼吸、流动和彩虹模式，适合做桌面环境光。亮度和灯珠数量可以配置，也可以随时关闭。接线与命令见 [灯带教程](ws2812-lighting.md)。

工位搭子的幽默来自植物自己的慢节奏：

- “已到工位。今天争取长片叶子。”
- “会议我听不懂，窗边我很擅长。”
- “先别给我加需求，我只是棵薄荷。”
- “这一小段，算数。叶子也替你记着。”

设备出现问题时直接说明原因，例如“水泵未启用”或“结果还没确认”，让使用者知道下一步该做什么。

## 从工位继续生长

后续开发包括更稳定的设备接入、植物观察记录、水位与灌溉反馈，以及面向不同板卡的适配器。设施农业和智能灌溉需要进一步加入分区、流量、阀门状态和离线控制。

查看 [功能进度与开发计划](roadmap-evidence.md)，或从 [硬件入门](hardware-quickstart.md) 接起自己的第一台。
