# 拍摄与分享工位搭子

用图片或短视频记录自己的工位搭子：植物、屏幕、灯带和小票都可以成为主角。网页录屏注明“网页演示”，设备照片注明实际使用的硬件。

## 画面与尺寸

- **3:4 图文**：可从1080×1440像素开始，标题尽量控制在两行，四边保留足够留白。
- **9:16 视频**：可从1080×1920像素开始，让屏幕、手部操作和植物落在中央，字幕避开平台按钮。
- **屏幕特写**：固定曝光与白平衡，先检查条纹和频闪。
- **灯带近景**：保留桌沿和环境光，既能看见灯珠，也能看见光落在桌面上的变化。

网页中的“导出3:4海报”可生成角色图片。外观概念模型与实物照片分别使用，方便观看者理解展示内容。

## 一组图文可以这样组织

1. 桌面全景：介绍自己的植物和工位搭子。
2. 屏幕特写：展示精灵、主题或番茄钟。
3. 真实读数：说明探头型号、原始值或校准结果。
4. 接线细节：拍清主板、接口与独立供电。
5. 一个完整操作：展示请求和对应的灯光或打印结果。
6. 项目入口：附上自己的改装说明或本项目教程链接。

游戏照料与真实设备操作放在不同镜头中。分享手机和控制台画面前，遮盖账号、通知和令牌。

## 30秒视频示例

| 时间 | 画面 | 字幕示例 |
| --- | --- | --- |
| 0–5秒 | 工位与绿植 | 我给工位招了个绿同事。 |
| 5–10秒 | 像素精灵眨眼 | 工资：一点电。KPI：长片叶子。 |
| 10–16秒 | 番茄钟或主题切换 | 不催我打卡，陪我做完这一小段。 |
| 16–24秒 | 一次已接通的读数、灯光或打印操作 | 展示实际操作与结果。 |
| 24–30秒 | 桌面远景和项目链接 | 你先下班，我负责发芽。 |

选择自己已接好的功能拍摄，保留同一次操作的连续画面。音乐、字体和照片使用适合分享渠道的授权素材。

花盆采用 Creeper 头造型时，可以从“以为会炸工位，结果只会发芽”的反差开场，再切到真实读数、灯光或一张打印出来的日签。展示所用设备时附上 [硬件图鉴与官方链接](hardware-catalog.md)，方便读者找到同款板卡。

## 可以借用的短句

- “这只苦力怕，只会发芽。”
- “没有爆炸，只有光合作用。”
- “今日工种：光合作用。当前进度：缓慢但在场。”
- “会议我听不懂，窗边我很擅长。”
- “我不卷。我卷的是叶边。”
- “这周先长一片，剩下的下周再说。”
- “今日低电量营业：人和植物都可以。”
- “先别给我加需求，我只是棵薄荷。”
- “下班通知收到。本人继续缓慢生长。”

## 分享你的接入方式

附上板卡、外设型号、固件版本、接线图和遇到的问题，其他人会更容易复现。更多内容见 [项目介绍](product-story.md)、[硬件入门](hardware-quickstart.md) 和 [视觉规范](design-system.md)。
