# 土壤与水箱校准

入口：**Indicator 设置 → 花盆连接 → 传感器校准**。中英文界面均可操作。参考值保存在 XIAO 主控的非易失存储中，正常断电重启后仍保留；更换 Wi-Fi、退出页面不会清除它们。重新标定不需要修改源码或刷固件。

## 先查看，再采集和保存

未装好水箱时，可以打开页面查看实时距离、拍摄界面操作；此时保持未标定，不把桌面或临时物体的距离存成水箱参考点。土壤未标定时显示 ADC 原始值，不推断植物缺水。

每点按一次“采集”，保持探头和介质不动，等待五份不同的实时数据。土壤五次读数的最大差不能超过40，水箱距离不能超过4mm；过期、无效、超时或不稳定时需重采。采集只修改屏幕中的草稿，**点击“保存校准”并看到“已保存并从主控读回”后才生效**。未保存就返回会丢弃草稿。

校准全过程不启动水泵、不打印、不切换灯。泵正在运行时不能保存校准；保存过程中不接受新浇水。保存失败、网络中断不会自动重复写入；结果未确认时先等待读回，必要时返回重新打开，检查已经保存的参考值。

## 土壤：同一探头、同一基质、同一深度

1. 在目标干燥基质中保持日常插入深度，等读数稳定，采集“干燥参考”。不要用悬空空气读数代替目标基质。
2. 将同种基质浇透并充分沥干，以同样深度采集“湿润参考”。保持模块电路部分干燥。
3. 两值须在0–4095内，差值至少64；支持数值随湿度上升或下降的两种方向。若太接近，检查接线、位置和基质，再采集。
4. 保存。屏幕、主控HTTP、YOYO土壤查询以及场景小票使用同一组值。已有小票预览是冻结快照，重新打开预览才会使用新状态。

百分比按干点0%、湿点100%线性换算，超出端点时限制在0–100%。它是这个探头与基质的**相对湿润程度**，不是实验测得的体积含水率，也不能直接作为所有植物的通用浇水阈值。

## 水箱：满水、缺水停泵、空箱

先完成水箱并固定探头，保持探头干燥、朝向水面，避开水流和箱壁。移动探头、换箱或改变安装位置后应重新标定。

| 参考点 | 如何采集 |
| --- | --- |
| 满水 | 加水到日常允许的最高水面，稳定后采集 |
| 缺水停泵 | 水面处于最低安全位置、仍能保护泵进水口时采集，预留实际装置需要的余量 |
| 空箱参考 | 空箱或定义好的零水位参考面，确保有可靠回波 |

单位为探头到目标面的距离mm。距离必须满足 `20 ≤ 满水 < 缺水停泵 < 空箱 ≤ 3500`，相邻参考点至少间隔10mm。若小水箱过浅，或空箱产生无效回波，不虚填数值绕过校验，应调整安装或测量方案。

保存后显示的是水位高度比例，不是剩余毫升。距离达到缺水停泵点、回波失效/过期、距离小于满水参考或校准被清除时，主控阻止浇水，并停止已经运行的泵。该规则仍需在最终水箱上验证。

**校准成功不会自动启用水泵。** 当前台架泵为独立12V、用户确认铭牌150mA和负载已接；水箱未完成，泵固件仍关闭。额定电流不代表启动电流。负载、泵进水/灌泵、保护、电源和实际运行测试完成后，再启用泵功能。

## 清除与更换设备

“清除参考点”需要再次确认，只清除当前传感器：土壤回到原始ADC；水箱回到距离显示并禁止浇水。清除也会保存，重启不会恢复旧参考点。另一组校准、Wi-Fi和手机绑定保持不变。

校准记录包含版本、修订号和校验值，以单条NVS记录写入并读回。过期修订的写入被拒绝，损坏记录不参与百分比或水位保护。主控存储不可用时页面禁止保存。刷写整个Flash或主动擦除NVS会丢失校准，常规应用分区更新不会主动清除NVS。

接口字段和请求格式见[设备协议](../device-protocol.md)。测试与实机状态见[验收记录](acceptance.md)。
