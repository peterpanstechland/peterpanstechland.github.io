# YOYO 日常交互与首次连接

更新：2026-10-29。私有Skill为 **RoboPlanter工位盆栽伙伴 0.4.0**。首次绑定和“读取工位状态”已通过；其余手机动作待分别验收。

## 找到六位配对码

1. 两板供电并接同一2.4GHz Wi-Fi，Indicator“设置 → 花盆连接”显示花盆可用。
2. 打开“YOYO与场景小票”，点 **“开启两分钟配对”**。
3. 手机系统蓝牙选择对应RoboPlanter，输入 **Indicator该页面显示的六位码**。不是手机锁屏密码，不在技能文件里。
4. 主控确认绑定后，打开手机Skill，说“读取工位状态”。

绑定存储在设备，设计上只需首次登记；主控重启保留绑定已验证，手机跨重启重连仍待单独验收。窗口过期时在Indicator重新开启并使用新码。当前固件按钮为“显示六位配对码”，PIN已放大。

一次仅支持一个BLE命令连接，调试App应先断开。“读取技能文件异常”先排查Skill安装/版本/有效入口，与输入蓝牙PIN是不同步骤。

## 五种自动场景日签

用户已选择命中场景后自动打印，默认开；可在同一设置页或语音中关闭。

| 表达 | 场景 | 短句示例 |
| --- | --- | --- |
| 早上好，上班打卡 | checkin | 今天慢慢来也行 |
| 今天吃什么外卖 | lunch | 先吃饭，再拯救世界 |
| 今天开了很多会 | meetings | 会议结束，脑袋下班 |
| 心累，想摸会鱼 | rest | 休息一下也算进度 |
| 今天不想上班 | lowbattery | 低电量也值得被照顾 |

每轮最多一张，同场景五分钟内最多一次。“别打印这次”覆盖当前触发；“以后别自动打印”保存关闭偏好；明确“打印一张”可手动打印。引用、否定、复述和“谢谢”不再出纸。

小票含Logo、场景短句、真实有效状态快照、三行可勾选手写待办、**完整78张牌随机一张及正逆位**。屏幕预览打开时抽一次并固定；语音场景在命令被接受后生成一次，不声称已经预览其牌面。塔罗为娱乐提示，不是事实预测。

设备端会议幸存签、Indicator预览与纸面一致已验收，手机自动触发待验收。超时只查原ID，不自动重印或重新抽牌。详见[工位日签](daily-ticket.md)。

## 番茄钟与声音

共享计时由XIAO负责，1–120分钟，默认25分钟。手机断开不取消计时；主控断电清零。Indicator同步状态，不打断正在进行的设置和确认。

D1内置 **RP2040 GPIO19无源蜂鸣器**，不是语音喇叭。180ms短音协议已部署，默认关闭，可在番茄钟页开启并保存；听音待确认。YOYO语音从手机输出。

系统提醒与番茄钟不同。日期、时区或“今天10:30已经过去”需澄清；只有明确“每天/工作日”才建重复提醒。工具确认前不宣称设置成功；提醒不等于自动打开AI、下单或打印。

## 对话节奏

小芽默认一至两句接住当下处境，再按需执行。“会议开麻了”可以说“今天是会议在上班，你在陪跑。”；“别建议，就想吐槽”就继续听，不强塞任务。只读查询或单独设备控制不会附送小票。回复以业务结果为准，不把工具已发送当成已出纸。
