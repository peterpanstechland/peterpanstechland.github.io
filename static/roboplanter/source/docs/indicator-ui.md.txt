# Indicator 像素工位伙伴

原版 SenseCAP Indicator D1，480×480 电容触摸屏。YOYO 负责自然语言交互；Indicator 提供植物精灵养成、真实状态和本地番茄钟。界面参考 Worker Smart Planter：炭黑底、奶油白信息卡、鼠尾草绿主色，搭配柔紫和水蓝。本轮首页加入薄荷、九层塔、蔷薇和多肉，从种子逐步成长，显示生命条、精灵心情和工位氛围；完整规则见[植物精灵说明](indicator-garden.md)。

这里描述的是 `firmware/indicator/` 的原生绘制实现。养成 v3 的原生预览直接运行固件绘图代码并导出帧，默认输出到 `build/indicator-preview-v3/`。[第一版原生动画](previews/indicator-worker.gif)与[第一版页面总览](previews/indicator-worker-overview.png)、`build/indicator-preview/`、设置版 `build/indicator-preview-v2/` 均保留作历史对照；旧浏览器 HTML 是更早的独立原型，不能代表当前布局。v3 在第一轮刷新中断修订后仍有偶发闪屏反馈；当前已刷入 VSYNC 双缓冲版本，96 次完整帧交换与存档读回通过，用户随后反馈“暂时没有再闪，触摸正常”，见[双缓冲修订记录](deployment/indicator-vsync-double-buffer.md)及[养成历史记录](deployment/indicator-garden-ui.md)。v2 字体、背光和 Wi-Fi 扫描已获用户确认，版本详情见[设置界面记录](deployment/indicator-settings-ui.md)。

## 页面与手势

顶部 Wi-Fi 与设置齿轮已重新绘制：Wi-Fi 使用宽扁的双弧线与底部圆点，以 2 倍整数像素显示；齿轮使用原生 32 px 细描边，外轮廓与中心小圆之间留白。两者纵向居中，设置菜单和信息页同步使用新字形，点击区域保持原尺寸，见[图标修订记录](deployment/indicator-icons.md)。

**植物精灵 → 今日状态 → 信息屏 → 照片屏 → 番茄钟。**

- 开机停在植物精灵首页，轻点植物本体进入今日状态。向左滑进入下一页，向右滑返回上一页，首尾不循环。首页“小花园”“照料小精灵”和“工位氛围”分别打开选种、照料和氛围面板，返回键关闭面板。
- 顶部返回键返回上一页；打开主题、硬件操作或确认页时，先关闭最上层页面。设置内返回上一级，主设置页再返回时关闭设置。滑动离开确认页不会发送操作。
- 顶部“主题”在任何页面打开 8 个主题；选中立即应用并存入 ESP32 Preferences，下次开机保留。齿轮进入设备设置。
- 手指抬起后才识别点击。横向滑动至少 60 px；触摸通信错误、多指或越界会取消这一段手势，直到真正抬手。
- 今日状态用四张卡显示土壤湿度、空气温度、空气湿度和泵/灯状态；硬件操作在单独面板内。切主题、翻页、计时不会触发浇水、灯光或打印。
- 浇水和打印先打开确认页；再次明确点击确认，且当前连接、新鲜度和设备能力仍满足条件，才提交一次指令。浇水显示配置的秒数，不推算毫升；打印展示固定 ASCII 便签内容。停泵直接提交，不增加确认步骤；网络停泵不是物理急停。
- 信息屏显示连接、采样距今、空气和 UV 原始数值，以及在手机上使用 YOYO 的提示。没有水位、可见光照度、流量、墙上时钟或 YOYO 在线状态数据，因此不照搬参考图中的水箱百分比、光照百分比、120 ml、日期时间或“已连接手机”。

土壤百分比需要有效且已标定的数据；空气湿度不能代替土壤湿度。缺失或未校准的数据用 `--`，保留的旧读数和旧设备状态会标注。空气和 UV 只显示原始 ADC，不转换成空气质量结论、lux 或光照百分比。

植物精灵根据物种与成长阶段呈现种子、叶片、花朵、果实或侧芽，生命与心情会影响表情。主体位置固定，每 5.3 秒眨眼一次、持续 260 ms；星点和庆祝粒子在小范围内变化。生命条、水分与养分均是本地游戏数据，不代表真实植物健康、设备在线或 YOYO 对人的情绪判断。虚拟照料从不提交水泵、施肥或打印命令。

真实硬件操作继续使用原来的状态和确认流程。只有新鲜状态确认泵正在运行时，操作页才显示运行动态；动画不代表测得的出水量或完成比例。`accepted` 表示受理，`completed` 表示软件任务完成；打印完成仅代表串口字节已发送。结果未知时不自动重发，界面要求现场核对后才能解除新动作锁定；停泵不受这项锁定限制，但仍需网络与设备能力可用。

## 植物精灵养成

四株植物独立保存，只有当前选中者累计在线陪伴时间和消耗；其他植物暂停，断电时全部暂停。成长需同时满足陪伴时间和成长值：萌芽为 5 分钟 / 8，枝叶舒展为 30 分钟 / 30，开花为 90 分钟 / 75，成熟为 180 分钟 / 140。首页显示距离下一阶段还差多少，两项条件都满足才进阶。

照料页提供虚拟浇水、施肥、除草和陪伴，具有需求判断与冷却；种子阶段暂不施肥。游戏生命最低保留 20，不会永久死亡。工位氛围由用户主动选择，改变陪伴短句；它与每株精灵自身的游戏心情分开。

显式操作约 2 秒合并保存，在线进度每 60 秒保存检查点。突然断电可能丢失最后一次保存后的进度；存储失败时显示“成长暂未保存”。完整数值、奖励和存档规则见[植物精灵说明](indicator-garden.md)。目前养成没有 YOYO Skill、MCP 或云端操作接口。

## 设备设置与文字

- **中文 / English**：切换主页面、养成面板、主题名称、操作说明和设置文字，语言选择本地保存。字体使用按项目文案生成的原生位图子集，分别栅格化为 16、24、32、48、64 px；较大文字不再放大 16 px 位图。照片标题和外部网络名称中的字仍受子集覆盖范围限制。
- **屏幕亮度**：支持减、加和滑条，范围 5–100%，即时调整 GPIO45 的背光 PWM，并保存本机设置。下限保留可见亮度；截图只模拟百分比，不能验证真实背光。
- **Wi-Fi**：后台扫描 2.4 GHz 网络，屏幕显示至多十个网络并可翻页；点选后用触摸键盘输入密码，支持大小写、数字、符号和空格。密码保持遮罩，不写入状态快照或预览日志。连接请求被接受不等于已经连通；连接失败会显示原因。提供恢复默认连接入口。
- **关于设备**：本机已确认为 D1，不含内置 CO₂/VOC 传感器，温湿度需外接。当前固件尚未读取 RP2040 上的传感器；今日状态仍显示来自 XIAO 的真实数据。

Wi-Fi 图标表示 Indicator 的网络连接状态，不能据此判断花盆在线。连接家庭网络不会自动改写 XIAO 的地址或令牌；底部花盆连接提示与采样新鲜度仍以设备 HTTP 响应为准。打开设置会收起硬件操作与确认层，设置中的点击、滑动和输入不会穿透成浇水、停泵、灯光或打印。切语言、调亮度和打开设置不会重置本地番茄钟。

## 番茄钟

提供专注 25 分、短歇 5 分、长歇 15 分。支持开始、暂停、继续、重置；运行或暂停期间需先重置才能更换时长。计时不依赖 Wi-Fi，翻页和换主题不会重置。完成后停在完成状态，不自动开始下一轮。完成 25 分钟专注时，当前植物获得一次成长值 +20、生命 +5、心情 +12；短歇、长歇、暂停或重置不发奖励，重复刷新完成页不重复奖励。

当前只在屏幕上提示完成；没有蜂鸣、手机推送或后台日程提醒。重启设备会清空当前计时，已保存的植物进度、主题、语言、亮度和网络设置会保留。当前 MCP 工具不提供养成、主题或番茄钟控制，也不向屏幕推送 YOYO 对话。

## 导入自己的照片

照片页默认显示空相册。当前版本支持把 1–4 张本地图片编入固件；不是手机实时传图，也不自动访问相册。需 Python 和 Pillow。

在项目根目录执行（替换为自己的图片路径）：

```powershell
python tools/pack_indicator_photos.py 'C:\Photos\窗边.png' 'C:\Photos\山野.jpg'
python tools/build_indicator_font.py --font .tools/fonts/NotoSansSC-Regular.otf
.\tools\build.ps1 -Target indicator
```

工具按 EXIF 方向旋转、居中裁切为 **400×280 RGB565**，去除 EXIF 等元数据，仅保留像素和文件名标题。每张像素约 224 KB，最多四张。照片使用前后按钮切换，左右滑动仍切换功能页。

生成的 `firmware/indicator/include/photos.local.h` 已被 Git 忽略；若把原图放入 `firmware/indicator/assets/photos/`，该目录也被忽略。照片像素会进入编译后的固件，因此分享私人固件前需检查内容。删除 `photos.local.h` 并重新构建即可恢复空相册。

源字体下载位置、许可与重生成说明见 `firmware/indicator/assets/fonts/README.md`。常规构建已经自带生成的中文字库，不必下载字体；修改中文标题或照片标题后才需重新生成。屏幕中文不等于热敏打印机支持中文，当前小票仍为 ASCII。

## 验证与实机检查

```powershell
.\tools\test-indicator-ui.ps1
.\tools\test-garden.ps1
.\tools\test-settings-ui.ps1
.\tools\test-indicator-font.ps1
python -m unittest discover -s tests -p test_indicator_assets.py -v
python tools/build_indicator_font.py --check
```

UI 模型检查覆盖页面边界、触摸释放/滑动隔离、无效触摸锁定、计时暂停与时钟回绕、主题与计时独立。原生预览运行实际 `main.cpp`，检查硬件操作、设置及养成覆盖层的手势隔离。养成测试覆盖成长门槛、需求判断、冷却、独立植物进度、专注奖励及存档恢复；字体检查覆盖字形边界、原生字号与全部五字号的字符覆盖。图片测试覆盖方向、RGB565 字序、透明背景处理和错误输入保留旧包。各版执行结果另见对应版本记录。

新版原生预览需先安装固件固定版本的 Arduino_GFX 依赖，并具备 Visual Studio C++ Build Tools、Python 和 Pillow。在项目根目录执行：

```powershell
.\tools\render-indicator-ui.ps1
# 可传入 -Python 'C:\path\to\python.exe'
```

工具通过桌面测试边界运行生产 `main.cpp`、设置、养成、植物精灵、主题、原生字号字形和照片绘图代码，并使用固定版本 Arduino_GFX 栅格算法生成 480×480 RGB565 帧。默认输出位于 `build/indicator-preview-v3/`，保留 v1、v2 目录不覆盖。中英文主页、设置、四物种成长阶段以及八主题 PNG/GIF 便于逐屏检查。`manifest.json` 记录来源文件哈希、语言、样例标记、字体格式和预览限制。

真实花盆状态固定为明确未连接的未知状态，不连接硬件、不发送指令，也不填充演示传感器读数。植物成长阶段使用明确标记的主机样例，便于一次查看各阶段，不将预览快进写入硬件。设置后端、存储与亮度为主机模拟：Wi-Fi 空列表、键盘及网络列表截图只用 `example` 样例名称，不扫描真实网络、不使用真实密码，也不连接外网。实际后端、持久化与背光需另行测试。

[旧 HTML 预览](previews/indicator-companion.html)是独立实现的早期原型，可参考导航意图，不能用它判断新版固件的布局、图形或帧率。原生截图更接近实际绘图结果，但仍不模拟 LCD 时序、PSRAM/DMA、背光、触摸硬件或实机速度；GIF 为 256 色，PNG 保留导出的像素颜色。

v2 的字体、背光与 Wi-Fi 扫描已有用户正常反馈。本轮养成版烧录后仍需核对种子初始状态、四株切换保留进度、虚拟照料与实体控制隔离、计时奖励、重启存档及长时间稳定性。五页手势、八主题可读性、语言保存和网络流程也需回归；生成预览不代表已经烧录。
