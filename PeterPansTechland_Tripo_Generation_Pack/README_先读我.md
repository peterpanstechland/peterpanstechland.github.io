# Peter Pan's Techland — Tripo 3D 生成执行包

**状态：生成前准备，0 个 Tripo 任务已提交，0 个 GLB 已交付。**

本包不是又一版主页，也不是 3D 成品。它包含用户认可的最新赛博朋克车库设计的独立参考裁图、13 个资产任务、官方 Tripo CLI 的本地批量执行器。当前聊天没有可调用的 Tripo 插件，执行环境无法连接其 API，故没有冒充已生成。

## 本地启动

需要联网的电脑、Node.js 20+ 与 Python 3.10+。已安装 Tripo CLI 时直接调用，否则通过 npx 使用官方 `tripo-cli`，不修改全局安装或系统执行策略。

Windows 双击 **START_WINDOWS.cmd**。macOS / Linux 运行：

```bash
bash start_macos_linux.sh
```

执行器先展示完整任务清单。输入 `GENERATE 13` 才批准本次 13 个新任务；未登录时调用官方 `tripo login` 打开浏览器，由本人核对验证码并授权。之后运行 `tripo doctor`，检查通过才开始生成。**不要将 API Key 发进聊天，不要写入网页、参考图或公共仓库。**

所有结果写在本包 `output/` 内，绝不覆盖现有博客主页或 `model-slots.json`。没有自动充值、自动重复扣费重试或自动部署。

只检查计划，不登录、不联网、不扣积分：

```bash
python run_tripo.py
```

限定资产的示例（本包默认已经包含完整场景，并非要求分多轮确认）：

```bash
python run_tripo.py --execute --only 01_garage_shell,04_lucky_cat,05_project_vending
```

`manifest.json` 是**本执行器的格式**，不是声称可直接传给 `tripo batch run` 的官方 YAML 格式。

`references/` 的裁图来自本次确认的概念分件图，仅保留单一主要对象；没有重新生成效果图。原始分件参考放在 `source_art/`，仅用于核对，**不会整张上传为一个不可拆的车库模型**。

参考裁图约 112–424 像素宽，多数不足 256 像素；没有把简单放大伪称为高清。有些图带旁边的装饰或 AI 绘制的文字，可能被一并重建。它们适合作为初稿轮廓输入，不能承诺直接得到参考图级别的生产资产。官方建议图片分辨率高于 256px；正式高细节迭代应替换为更高分辨率的独立资产原图。

图生模型任务仅传图片；`prompts/` 对应文字是美术和后处理要求，**不会假称被图生模型接口同时执行**。只有 `mode=text` 的任务实际提交文字。生成结果是否满足参考要求，必须看真实输出再判断。

## 不会重复的错误

- 模型存在之后才谈接入 Three.js；本包不碰线上主页。
- 作品展示区、工具创作区是两个独立模块，不混成一张工作台。
- 概念图中人物不是用户确认的真实头像；招牌任务只生成空框，后续使用网站已有且核对过的 profile 图片贴图。
- 招财猫是门口的角色，不是品牌 Logo；图中错误猫头标识必须清理。
- 卷帘门上的 `Peter Pan's Techland` 涂鸦在后期准确绘制并贴到连续 UV 上，不依赖模型猜写英文。
- 任务图中“300+ / 50K+ / 100+”等数字和 SIGN IN 按钮只是 AI 设计图内容，不是用户真实数据或已实现功能，不带入主页。
- 三维模型的 PBR 材质不等于已做好霓虹 Bloom、雨夜反射与镜头动画；这些属于 Three.js 场景集成。

## 运行结果及中断

CLI 等待任务并下载结果；执行器随后检查 GLB 文件头、JSON、mesh 和 node 是否存在，生成 `qa_report.json`。这只是基本结构检查，不是视觉或动画验收。

状态记录在 `output/runner_state.json`。已下载的同一输入会跳过；中断、接口报错、未知任务状态不会自动重新提交。先查看提供方的 `task.json` 与 `tripo history`，防止一次网络错误变成重复收费。

如果 CLI 登录、参数或服务端版本发生变化，执行会停在失败处，不会继续批量消耗积分。可用 `tripo docs --topic commands/make` 核对安装版本的参数。
