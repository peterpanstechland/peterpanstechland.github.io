# 六条流程，让架构自己讲一遍

**TEAM7 · 战术犯规队 / COURTSIDE IQ**

从主播进入工作台，到一段作品被公开观看，一次操作会经过哪些服务，结果又怎样留下来？这六组流程分别解释入口、媒体任务、视觉证据、Agent 解说、节目回放和运维支路。页面默认展示静态总览；点击 **播放动画**，可以逐步观察高亮的节点与连线，点击 **查看静态总览** 即可停止动画。

这些图来自项目源码中的实现关系，是逻辑流程讲解，**不会调用 AWS，不查询线上账号，也不代表所有支路都会在一次请求中执行**。移动圆点只提示正在讲解的路径，不表示实测延迟或吞吐量。

## 先读懂连线

- **青色实线：** 同步调用或交互。
- **棕色虚线：** 异步处理或持久任务。
- **蓝色实线：** 数据、文件或版本。
- **玫红色实线：** 人工确认或独立支路。

高亮节点表示当前步骤涉及的职责。总览保留了可选路径和支撑关系，不意味着一次操作必须依次调用全部服务。

## 01 入口与控制面 {#entry-control}

**CloudFront · API Gateway · Cognito**

CloudFront 提供统一的网页入口；进入应用后，HTTP 控制请求、WebSocket 消息和浏览器语音转写分别走自己的路径。Cognito 为直接转写提供临时凭证，主播操作权限则由应用会话令牌控制。

<FlowAnimation id="01-entry-control" title="入口与控制面" steps={7} seconds={16} />

**实现边界：** 网页与公共资源可以缓存，`/api` 不缓存。WebSocket 消息与转写音频不经过静态页面缓存；临时转写凭证也不等于主播权限。可核对[网页分发配置](https://github.com/peterpanstechland/NBAHackathon/blob/f43f4e0b0b1424b2aa36cd09301ac2ac047cc32c/infra/lib/constructs/web.ts)和[浏览器转写代码](https://github.com/peterpanstechland/NBAHackathon/blob/f43f4e0b0b1424b2aa36cd09301ac2ac047cc32c/web/src/lib/voice.ts)。

## 02 媒体任务与版本化存储 {#media-storage}

**S3 · EventBridge · Step Functions · MediaConvert**

先登记素材，再把原片直接上传到 S3；对象事件进入幂等启动逻辑，Step Functions 协调后续阶段，MediaConvert 负责转码和抽帧。媒体及带版本的分析产物进入 S3，状态与索引保存在 DynamoDB。

<FlowAnimation id="02-media-storage" title="媒体任务与版本化存储" steps={8} seconds={17} />

**实现边界：** 图中上传链路针对已登记的 MP4。应用 API 负责登记和签名，大文件不穿过应用 Lambda；桶里任意一个对象变动，也不意味着都会启动分析。可核对[流水线基础设施](https://github.com/peterpanstechland/NBAHackathon/blob/f43f4e0b0b1424b2aa36cd09301ac2ac047cc32c/infra/lib/constructs/pipeline.ts)和[媒体处理工作流](https://github.com/peterpanstechland/NBAHackathon/blob/f43f4e0b0b1424b2aa36cd09301ac2ac047cc32c/services/pipeline/workflow.py)。

## 03 视觉观察与模型推理 {#vision-inference}

**SageMaker AI · Rekognition · Bedrock**

SageMaker 运行自定义视觉容器，Rekognition 从采样画面中读文字，Bedrock 上的 Qwen 结合选定 JPEG 和结构化上下文理解画面。源时间与标注修订号把输入连接起来；官方快照、视觉观察和模型假设仍分别保留。

<FlowAnimation id="03-vision-inference" title="视觉观察与模型推理" steps={7} seconds={16} />

**实现边界：** ViTPose 属于归档请求分支，能否使用取决于模型是否加载。分割轮廓或临时轨迹不能自动证明 NBA 球员身份；相对深度不是米制距离；Qwen 接收选帧，并不直接读取整段 MP4。可核对[视觉服务](https://github.com/peterpanstechland/NBAHackathon/blob/f43f4e0b0b1424b2aa36cd09301ac2ac047cc32c/services/courtvision/server.py)和[画面推理代码](https://github.com/peterpanstechland/NBAHackathon/blob/f43f4e0b0b1424b2aa36cd09301ac2ac047cc32c/services/shared/src/nba_copilot/scene_model.py)。

## 04 Agent 的运行环境与解说资产 {#agent-audio}

**AgentCore · Strands · Bedrock · Transcribe · Polly**

预分析与暂停帧问答分开组织：前者使用三节点 Strands 图，后者使用单 Agent 和证据工具。关键帧稿件保留语言、标注修订号和文本版本，供主播修改、审核；Polly 配音可以复用，Transcribe 则处理显式开启的麦克风输入。

<FlowAnimation id="04-agent-audio" title="Agent 的运行环境与解说资产" steps={8} seconds={17} />

**实现边界：** AgentCore 托管应用代码，Strands 编排 Agent，Bedrock 执行模型推理。当前 Runtime 网络配置为 `PUBLIC`，Claude 使用全局推理配置文件，不能将它画成仅在 VPC 内运行。重做 AI 分析不会覆盖已审核稿件；自动翻译与主播声音克隆没有在本次实现。可核对[运行时配置](https://github.com/peterpanstechland/NBAHackathon/blob/f43f4e0b0b1424b2aa36cd09301ac2ac047cc32c/infra/lib/constructs/agents.ts)和[版本化播报资产](https://github.com/peterpanstechland/NBAHackathon/blob/f43f4e0b0b1424b2aa36cd09301ac2ac047cc32c/services/shared/src/nba_copilot/keyframe_narration.py)。

## 05 从浏览器录制到公共节目 {#production-broadcast}

**Web Audio · S3 · DynamoDB · CloudFront**

浏览器分别保存原片、固定的节目混音音轨和 JSON 操作记录。上传文件通过完整性检查后，作品才成为 `READY`；选中的作品再使用同一个服务器节目时钟，让观众从当前进度加入循环播放的录制节目。

<FlowAnimation id="05-production-broadcast" title="从浏览器录制到公共节目" steps={8} seconds={17} />

**实现边界：** `READY` 检查文件是否完整、结构是否可用，不验证篮球事实。JSON 需要本项目回放器，不是通用 EDL 交换格式。CloudFront 提供观看页面，媒体通过限时签名 URL 读取并续签；开启声音仍受浏览器自动播放策略约束。导出单个合成视频需要渲染和编码。可核对[作品验证逻辑](https://github.com/peterpanstechland/NBAHackathon/blob/f43f4e0b0b1424b2aa36cd09301ac2ac047cc32c/services/shared/src/nba_copilot/productions.py)和[公共回放实现](https://github.com/peterpanstechland/NBAHackathon/blob/f43f4e0b0b1424b2aa36cd09301ac2ac047cc32c/web/src/surfaces/broadcast/PublicProductionPlayback.tsx)。

## 06 运维和可选第三方 {#operations-external}

**IAM · Secrets Manager · CloudWatch · SQS · Roboflow · Tripo**

权限、密钥读取与日志支撑应用运行。失败留存、可选外部图片诊断和角色资产制作各有入口；动画中的讲解顺序，不代表一次请求会线性调用全部服务。

<FlowAnimation id="06-operations-external" title="运维和可选第三方" steps={8} seconds={17} />

**实现边界：** SQS 接收异步 Worker 未处理的失败，不会自动重放。Roboflow 只有显式开启才向外部 API 发送 JPEG；Tripo 属于资产创作阶段，浏览器使用现有 GLB 驱动动作，互动时不会再次调用生成 API。日志与失败指标也不代表已经接通自动处置。可核对[Worker 失败目的地](https://github.com/peterpanstechland/NBAHackathon/blob/f43f4e0b0b1424b2aa36cd09301ac2ac047cc32c/infra/lib/constructs/realtime.ts)、[可选诊断支路](https://github.com/peterpanstechland/NBAHackathon/blob/f43f4e0b0b1424b2aa36cd09301ac2ac047cc32c/services/pipeline/roboflow.py)和[本地角色动作](https://github.com/peterpanstechland/NBAHackathon/blob/f43f4e0b0b1424b2aa36cd09301ac2ac047cc32c/web/src/three/TeamMascotModel.tsx)。
