# 2026 深圳 Maker Faire · MAKERS CHALLENGE

## BEG. BUILD. SHOW.｜化缘、造物、开演。

**不带预先完成的整机，不按固定 BOM 采购。走进展会，向不同展位的 Maker 礼貌“化缘”零件、借设备、求技术支持，在现场把看似不搭界的东西拼成一个真的能跑的 Demo。**

## 01｜活动理念：把整个 Maker Faire 变成一个巨大的创客工具箱

传统展会主要是看作品、逛展台、交换名片。我们希望反过来：**参赛者不知道最后会拿到什么，却要在两天内完成一个作品。** 每个自愿参与的展位都是一站零件补给站，也是技术顾问和创意故事的一部分。

这个活动不是单纯比谁买得起硬件，也不只是比代码写得快。真正的挑战是**社交协作、设计取舍、跨模块集成、工程动手与 Live Demo**。

- **对参赛者**：走出自己的舒适区，练习与硬件厂商、独立 Maker、工程师沟通，在限制下完成快速原型。
- **对展商**：自己的产品不只陈列，而是在别人的 Demo 中成为关键部件，被真实使用和展示。
- **对观众**：近距离看创意从碎片、线材和失败里长出来；可以见证调试、参与投票和互动。
- **对社区**：把展商、项目与人真正连接起来，每件作品都有可追溯的 Maker 贡献故事。

**活动口号**：**BEG. BUILD. SHOW.** ／ **MAKE SOMETHING RIDICULOUS.** 「化缘」是创客文化里的玩笑表达，绝不代表强制索取。

## 03｜谁可以参加？可以带什么？

建议每队 2–4 人，鼓励硬件 + 软件 + 机械 + 艺术等跨学科组队。个人报名者可以申请现场匹配队友。未成年人须符合主办方现场管理要求，取得监护人同意，涉及热工具、切割和电源操作必须由合格成人监督。

**允许自带：**笔记本电脑、编程环境、常规手工具、安全眼镜、学习资料、已有 SDK、框架、开源库、调试软件，以及自有的专业技能。使用 AI 编程工具也是允许的。

**不能自带：**已完成核心功能的参赛整机、为本挑战提前组装好的完整硬件作品、为绕过现场化缘机制携带的未申报高价值模块。不能从展位直接拿走未经允许的设备或展示样品。具有无障碍或特殊辅助需求者，可由现场团队安排公平的支持方式。

## 04｜核心机制：Maker Passport 创客化缘护照

每支队伍领取一份**Maker Passport（纸质护照 + 可选二维码）**。加入挑战的展商可在摊位展示“CONTRIBUTOR / 友好补给站”标识。队伍每获得一次材料、借用、协作或技术指导，都在护照中登记，并请展商盖章/签名确认。

### 五种可登记的贡献

| 类型 | 是什么 | 必须登记什么 |
| --- | --- | --- |
| **GIFT / 赠送** | 开发板、传感器、按钮、灯带、小马达、线材、结构件、耗材等 | 展位/人员、零件名称、数量、赠送确认、领取时间 |
| **LOAN / 借用** | 相机、机械手、贵重开发板、专用仪器等可回收物品 | 物品编号、交接状态、允许用途、借用人、归还时间和状态 |
| **TOOL ACCESS / 设备使用** | 焊台、3D 打印、示波器、仪表、台钻等共享工具 | 使用工位、使用时段、操作员、安全要求与耗材 |
| **MENTOR HELP / 技术支持** | SDK 讲解、原理图检查、驱动调试、设计建议 | 导师与展位、问题、帮助内容 |
| **EXCHANGE / 队伍交换** | 团队之间交换不合适的零件 | 两队、交换物、原始来源及捐赠方是否允许转交 |

### 化缘公平规则

1. **展位完全自愿**：每个展位自行决定是否参加，能提供什么、多少件、能不能借，任何时候都可拒绝；禁止施压或扰乱展位秩序。
2. **每队每次从一个展位最多领取一件赠品**是建议上限，具体以展商承诺的数量和条件为准，也可以采用统一物资池分配。
3. 鼓励每队拜访**至少 5 个不同展位**，最终作品尽量实质集成**至少 3 个不同展位提供的材料/零件**。如果供应不足、展位分布不合理、无障碍条件受限，执行方应及时调整或豁免门槛，不因展商拒绝捐赠而处罚队伍。
4. **不允许靠购买取胜**：挑战开始后不得额外直接购买核心比赛模块；基础耗材由公共物资池统一发放。有特殊合理需要时由现场负责人审批并记录。
5. **贵重设备共享**：昂贵开发板、仪器、机械组件优先使用统一登记和预约轮换。品牌和物品标价不计入得分，不能给个别队伍私下提供不公平的独占资源。
6. **可交换、可求助**：可向展位工程师求助，也可在队伍间交换，前提是遵守原捐赠和借用条款，记录零件的流转轨迹。借来的东西不能擅自赠送或互换。
7. **隐藏任务（可选）**：主办方给每队相同级别的一件神秘材料，例如小黄鸭、旧鼠标外壳、纸盒或电话听筒，要求有意义地集成到 Demo；仅在供应充足且完成安全评估时启用。

**基础资源池**建议提供面包板、Dupont 线、连接器、电阻、胶带、扎带、螺丝、低压电源、防护用品及少量通用控制板（视赞助情况）。它是公平底座，而不是提前发放整套答案。

### 贡献护照模板字段

`Team ID` · `Booth / Maker` · `Type: GIFT | LOAN | TOOL | MENTOR | EXCHANGE` · `Part / Service` · `Qty` · `Conditions` · `Asset ID` · `Checkout` · `Return by` · `Contributor stamp / approval` · `Photo permission`。

建议设置一个现场登记台，维护 Google 表格或同等后台清单；网络不可用时提供纸质双联收据。公开作品卡只展示经同意的商家与协作者名称，个人电话、私人信息不公开。

## 05｜三阶段挑战流程

### PHASE 01 — BEG｜全场化缘

签到领取护照，听取安全说明，分组查看哪些展位自愿参与。大家到指定范围内的展位沟通：**「我们正在做一个现场 Maker Challenge，能不能借你们的技术、零件或者一点时间，把它装进一个新的 Demo？」** 尊重展商的时间和展览正常运营。领取之前必须询问，同意后登记，不得拆用正常展示装置。

### PHASE 02 — BUILD｜极限缝合

回到工坊清点物料，用白板或纸画出简单系统架构，先确定电源边界，再把一个最小交互跑起来。按规则预约焊接台、打印机、工具和导师，合理分工：结构/电路/嵌入式/交互/拍摄。鼓励记录问题和解决方案；AI 辅助工具允许使用，但团队必须理解并自行完成关键集成。

### PHASE 03 — SHOW｜现场开演

建议每队 **3 分钟 Pitch + 2 分钟评审提问**。必须运行真实作品，而不只是播放 PPT 或渲染动画。演示要说清楚**来自哪些展位、用了什么、最难的技术问题是什么、作品到底能做什么**。视频可以作为补充证据，但不能替代主奖的现场演示。失败也可以坦诚讲原因，评审按实际工作程度打分。

## 07｜评分机制与奖项

**安全合规是前置门槛，不是花钱可以买到的加分项。** 有危险的作品须整改，严重违规或拒不整改将暂停演示；可在截止前修复轻微问题。

| 评分维度 | 分值 | 看什么 |
| --- | ---: | --- |
| **现场 Demo 完成度** | **30** | 核心功能真实可跑、交互清晰、可复现 |
| **创意与整活程度** | **20** | 脑洞、惊喜感、玩法原创性 |
| **跨展位协作与整合** | **20** | 不同展位贡献真正集成、完整署名、尊重合作 |
| **工程能力与可靠性** | **15** | 电路安全、架构合理、问题定位与稳定性 |
| **演示故事与表达** | **10** | 三分钟能讲清楚原理、意义和协作过程 |
| **可持续与资源利用** | **5** | 废料再利用、维修意识、减少浪费 |
| **总分** | **100** | 同分优先比较 Demo 完成度，再由评委讨论决定 |

建议奖项：**FrankenMaker 最强缝合怪奖**（跨展位集成）；**最没用但好玩的发明奖**（抽象整活）；**硬核 Maker 奖**（工程能力）；**赛博丐帮帮主奖**（最强社交协作）；**观众人气奖**（现场公开投票）。证书、贴纸、器材、现金或礼品以最终赞助为准，**目前不承诺奖金**。赞助商不得购买评审席位、操纵评分或要求独家倾斜。

## 08｜工坊、设备使用和现场安全

### 场地分区建议

签到/护照区、物料登记柜台、公共零件池、队伍工作桌、焊接/热工具区、打印与加工区、低压电源与充电区、展示/评审台、回收与垃圾分类区、通道和消防出口。需要能锁存贵重借用物的空间，明确每个工位负责人。

### 安全底线（拟议，待主办方及场地方审核）

- 默认使用**低压直流 5–24V**、带保护的电源，检查极性、绝缘、线路和电流限制。**禁止参赛者在开放工位自行制作或操作裸露 220V 市电电路**；场地固定电气设备仅由合格人员安装和检查。
- 禁止明火、烟火、危险化学品、可造成伤害的发射器、武器、3B/4 类激光器等；高速旋转、高扭矩机械、移动机器人和高功率器件须经额外风险评估并隔离保护。
- 锂电池仅使用完好、带适当保护和匹配充电器的电池组；鼓包、破损电池不可带入；充电地点和应急处理须由安全负责人确认。
- 焊接、切割、3D 打印等需在合规通风和防护条件下由工具管理员监督；佩戴合适护目镜；儿童只能在监护与授权范围内使用相应工具。
- 摄像头、麦克风和 AI 识别不得未经同意采集个人隐私；无线设备应遵守频谱与场馆规定，禁止未授权扫描或干扰网络。
- 高价值借用设备需记录编号、照片/状态、使用边界、借用人、期限和归还结果；**保险、赔损、押金或免押条款须在活动前由双方书面确认**，不能现场随意决定。
- 所有人均可针对明显风险喊 **STOP**；安全员有权暂停演示、切断供电并按场地方流程疏散。

### 借物与归还操作

展商登记设备 → 检查功能/外观 → 生成借用凭证（两份）→ 责任人签收 → 标注允许使用地点与范围 → 借用期结束当面核验 → 双方确认归还。设备丢失、损坏处理走活动前约定的合同及保险流程。**捐赠**与**借用**不混用，任何未经明确转让的设备都必须归还。

## 10｜参赛最终交付清单

1. **项目卡**：队伍名、作品名、功能一句话、主要负责人。
2. **Maker Passport**：各展位提供的零件、借用、工具使用与技术支持，确认是否完成归还。
3. **真实 Demo**：有现场安全检查，通过后进行真实演示；附最简架构图或接线图。
4. **3 分钟故事**：介绍创意来源、不同展位物料的组合方式、失败或解决的难点、感谢贡献者。
5. **传播材料**：2–5 张照片或 30–90 秒演示视频、简单 BOM、允许公开的赞助与展商名单。

**开源鼓励但不强制**：作品代码可根据队伍及第三方许可开放；摄影、商标、保密技术与原开发者权益受到尊重。主办方应在报名条款中明确作品展示许可，不默认获得参赛作品的商业所有权。

## 11｜LOOKING FOR SPONSORS：展位产品、设备与服务

## 13｜筹备里程碑与 Go / No-Go

| 节点（建议） | 关键结果 |
| --- | --- |
| 尽快 | 向展会主办方提交独立配套活动提案，确认能否办、如何命名与宣传 |

**不满足条件就不强行举行**：若没有主办方和场地许可、没有足够安全监督、借物法律关系未落实、展位太少，则缩小范围、延期，或另行举办**不冒用官方名义的独立线下聚会**。

## 14｜常见问题

**展位必须给零件吗？** 绝不。只有自愿加入并明确同意的捐赠才可领取；展商可以拒绝任何请求。

**能买零件吗？** 为保持玩法公平，赛中原则上不能为参赛核心功能另行采购；公开登记的基础消耗物资与经批准的合理特殊需求例外。

**自带电脑、已有代码、AI 工具可以用吗？** 可以。重点是不能把已完成的整机带来当作现场制作成果。

**物料不够怎么办？** 通过基础物资池、共享预约、交换与根据真实供应调整跨展位要求来保障公平，不强制向展商索取。

**作品归谁？** 队伍拥有自行创作部分和明确捐赠给队伍的物品，受第三方许可和事先约定约束。**借来的设备必须归还。**

**报名、奖金和主办方确认了吗？** 目前都没有。这里是独立活动提案，只有参赛意向与合作征集，不能作为入场/赛事资格证明。
