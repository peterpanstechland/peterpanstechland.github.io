# LOOKING FOR SPONSORS

## 你的产品 × 他们的奇怪脑洞 = 一件真正能跑的作品。

这一次，我们不只征集 Logo 和活动经费。

**正在寻找愿意一起整活的品牌、展商、开发板厂商、设备商、创客空间、3D 打印服务、工程师与支持者。** 让参赛者在展会上向各个自愿参与的展位“化缘”一件产品、一个模块、一些材料，或者获得一段设备使用时间和技术帮助，最后现场做出新 Demo。

:::caution 独立活动企划 / 当前为合作意向征集
本挑战由 **彼得潘的科技谷（Peter Pan's Techland）** 独立提出，拟与 **2026 年 12 月 12–13 日的深圳 Maker Faire** 同期开展。挑战赛尚未获得展会主办方的正式确认或授权；参与展商、赞助商、场地、最终权益均未确认。目前征集**合作意向**，不是代表主办方收费或授权官方赞助。
:::

## 01｜为什么值得参与？

传统展会里，产品往往是静态展示。Makers Challenge 希望让它成为别人作品的一部分。你的开发板可能遇到别家的传感器，你家的马达可能被焊成一台没什么用但超好玩的机器人。

- **真实产品上手**：有工程师亲手接线、调试、调用 API，发现真实的开发体验。
- **跨品牌生态协作**：不同产品通过 Maker 的脑洞连接，展示意想不到的组合。
- **创客圈口碑与反馈**：得到关于易用性、文档与接口的现场反馈。
- **可追溯的曝光**：每件作品通过 Maker Passport 标记展位、产品型号与贡献故事，经同意后公开。
- **内容共创**：作品照片、短视频、Demo 片段、活动回顾以及展商采访，可以成为真实社交素材。

以上均为**拟议合作价值**，并不保证曝光量、销量、转化、官方背书或指定舞台权益。

## 02｜我们正在征集什么？

| 合作类别 | 欢迎提供 | 交付方式 |
| --- | --- | --- |
| **A｜展位产品 / 硬件赠送** | 开发板、传感器、屏幕、伺服电机、电机驱动、灯带、按钮、数据线、PCB、结构件、边角料 | **GIFT / 赠送**：明确数量、规格与归属转移 |
| **B｜设备借用 / 可回收器材** | 摄像头、机械手、贵重开发板、调试仪器、单价高的硬件 | **LOAN / 借用**：提前登记、限定用途、约定归还 |
| **C｜共享工坊 / 工具使用** | 焊台、3D 打印机、示波器、万用表、可调电源、工作台、加工工具 | **TOOL ACCESS / 使用**：现场预约、有操作员或监督 |
| **D｜技术导师 / 展位互动** | 嵌入式、AI、软件开发、机械结构、设计和 SDK 工程师 | **MENTOR / 支持**：技术辅导、调试帮助、短时驻站 |
| **E｜赞助经费 / 后勤 / 内容** | 场地、桌椅、电力、保险、耗材、奖品、运输、餐饮、拍摄、直播、视频 | **CASH / SERVICE**：按双方书面约定执行 |

### 最希望拿到的产品与材料

- **主控与算力**：ESP32、Arduino 兼容开发板、RP2040、STM32、树莓派 / Linux SBC、通信扩展板、USB 串口模块。
- **各类传感器**：陀螺仪/IMU、红外、PIR、ToF、超声波、触摸、声音、RFID/NFC、视觉模组、按键开关。
- **动作与机械**：低压电机、微型舵机、轮子、减速机构、驱动板、连杆、支架、齿轮、打印件。
- **交互输出**：LED 灯带/灯环、OLED/TFT/e-paper、蜂鸣器、小扬声器、振动马达、小票打印机（合规供电）。
- **基础耗材与废料**：杜邦线、连接器、面包板、电阻、LED、扎带、螺丝、胶、外壳、切割边角料、3D 打印耗材。
- **共享设备**：焊台、示波器、万用表、电流受限可调电源、3D 打印设备、压线钳、受监督的安全加工工位。
- **趣味材料**：小黄鸭、旧键盘/旧鼠标、玩具外壳、纸板、包装材料、废旧无危险组件等。

可以是可用的旧物、展示样品之外的备件、样品包或少量新品；**不需要捐出昂贵的展品**。昂贵设备更适合提供**限时借用或预约体验**。

## 03｜每个展位怎样参加？

不需要每个展位都承担很大成本，以下合作方式可选其一或组合：

1. **「给一件」补给点**：愿意的展商为到访队伍提供一件小物料（以库存为准，每队每次最多一件为建议而非强制）。
2. **「借一下」设备点**：提供一台可借出的设备或专用模块，明确借期、使用边界与归还责任；高价值物品统一纳入设备池。
3. **「教一下」技术点**：工程师给出 5–15 分钟说明，讲 SDK、接口、接线或帮助排障。
4. **「挑战一下」任务点**：给 Maker 一张趣味任务卡，例如用某个传感器做出一个让人想不到的交互。
5. **「加工一下」工坊点**：开放有限时段的打印、焊接或安全加工设备，由工作人员监督并登记耗材。

**摊主可以拒绝、随时暂停或限制数量**，不会因为不给东西就受到不利评价。不能拆展位设备，不能挡住正常顾客或未经同意拍摄。

## 04｜借用设备、产品归属与责任（必须写清楚）

**赠送 ≠ 借用 ≠ 设备使用。** 三类不同的权属和责任关系必须分开记录。

### 设备借用 SOP

1. **活动前清单**：贡献方填写设备型号、数量、资产编号、外观/功能状态、允许使用方式、是否含耗材，以及可借用的最长时间。
2. **权属确认**：赠品需明确转让；借用品明确归贡献方所有；工具使用只获得预约使用权，不能搬走。
3. **风险协定**：双方与正式组织主体在活动前书面明确押金是否需要、保险范围、损坏/丢失处理、责任主体、赔付边界和免责事项；不在现场临时口头约定。
4. **交接确认**：扫码/登记 → 检查拍照（如适用）→ 责任队伍签收 → 标示截止归还时间。
5. **安全与使用边界**：在批准区域使用，不得擅自拆改、危险供电或转借第三方；公共设备按预约公平轮换。
6. **当面归还**：关机、检查配件/功能与外观 → 双方签字确认归还；争议按约定程序处理。

高价值设备需要管理员统一保管。**在保险和借用责任未敲定前，不接受高价值设备借用**；可以先考虑低风险、受监督的现场演示。

## 05｜赞助和展商能获得什么？

| 类型 | 拟议合作展示与回馈（均须审批及授权） |
| --- | --- |
| **Contributor / 展位共创者** | Maker Passport 盖章、作品来源清单、参与展位名单 |
| **Hardware Partner / 产品支持** | 作品里注明品牌/型号；活动技术复盘、感谢名单 |
| **Tool Partner / 工具支持** | 共享工坊的设备来源标识、使用记录、活动回顾感谢 |
| **Community / Mentor Partner** | 技术导师致谢、经允许的采访/合影、社区内容 |
| **Supporting Sponsor / 后勤资金** | 经主办方同意的支持方名单、现场指示牌或回顾材料 |

*权益不是预售的官方赞助包*：未获主办方许可，不擅自使用 Maker Faire 官方 Logo、不承诺展位、展馆广告位、官方公众号推送、媒体阅读量或独家排他。商业品牌使用、拍摄与活动衍生内容需各方同意。**赞助不影响参赛评分、公平取材、评委及奖项**。

## 06｜首届拟议规模与预算方向

目标 **8–12 支队伍、20–30 个自愿参与展位、两天**。依据 10 队小规模活动的工作假设，基础耗材、物料印刷、布场、工具与安全、内容记录、奖品和应急费用合计**初估人民币 8,000–20,000 元**，不含若发生的正式场地租金、保险、付费人力、税费或大设备租赁费用。这不是正式报价，也不是已确认赞助额。详情参见[完整企划预算](/docs/challenges/2026-shenzhen-maker-faire)。

**合作优先级**：主办方批准与安全工坊 → 自愿展位 → 共享设备和电力 → 基础耗材与导师 → 拍摄与可选奖品。可以提供**实物支持**替代部分现金开支。

## 08｜合作推进流程

**现在**：征集兴趣和可提供资源 → 与主办方讨论活动许可与区域。

**获得批准后**：确定安全负责人、场地与时间、借物协议、保险/责任、品牌与拍摄许可、物资数量及共享预约方法。

**活动前**：确认库存、联系队伍、给展位发送标识与 SOP、试运行护照和借物登记。

**活动中**：捐赠/借用记录、技术支持、产品故事采集、随时处理安全或公平性问题。

**活动后**：设备清点归还、发布经允许的贡献者名单/作品视频、活动复盘和合作反馈。
