# CHALLENGE / MAKE SOMETHING RIDICULOUS

**BEG. BUILD. SHOW.** No fixed BOM. No pre-built winner. Collect components with permission, build a functioning demo, and credit the maker community that made it possible.

[**→ Enter the cinematic Challenge landing page**](/challenge)

## Featured concept: 2026 Shenzhen Maker Faire · Makers Challenge

**Proposed for December 12–13, 2026 · Nanshan, Shenzhen.** The Maker Faire event dates are official; **our Makers Challenge is an independent proposal seeking organizer approval and partners**.

Join a proposed two-day hardware scavenger hunt: teams visit participating exhibitor booths, politely request **one available item or access to tools**, log it in a **Maker Passport**, and remix parts from different makers into a real live demonstration. Participation is optional for booths.

| BEG | BUILD | SHOW |
| --- | --- | --- |
| Source donated parts, approved device loans and advice | Combine, solder, print, code and test | Live demo + maker credits + awards |
